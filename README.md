# ARTEZA-SAMP API

Полнофункциональная реализация всех типов API для современных приложений.

## 🚀 Типы API

### 1. **REST API**
- Стандартный HTTP запросы
- CRUD операции
- Аутентификация и авторизация
- Обработка ошибок

### 2. **GraphQL API**
- Гибкие запросы данных
- Типизация схемы
- Подписки в реальном времени

### 3. **WebSocket API**
- Двусторонняя коммуникация
- Реал-тайм обновления
- Чат функциональность

### 4. **gRPC API**
- Высокопроизводительное взаимодействие
- Бинарный протокол
- Потоковая передача данных

## 📦 Установка

```bash
git clone https://github.com/superkaternet-dev/ARTEZA-SAMP.git
cd ARTEZA-SAMP
npm install
```

## ⚙️ Конфигурация

```bash
cp .env.example .env
# Отредактируйте .env файл с вашими значениями
```

## 🏃 Запуск

### Разработка
```bash
npm run dev
```

### Продакшен
```bash
npm start
```
